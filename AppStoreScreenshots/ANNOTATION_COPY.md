## Typography Specs

| Element | Value |
|---------|-------|
| Font family | SF Pro Display Bold (or Helvetica Neue Bold) |
| Headline size | 48–64pt (scale proportionally per platform) |
| Subline size | 28–36pt |
| Text color | White (#FFFFFF) |
| Drop shadow | 2px black, 40% opacity, y-offset 1px |
| Alternative style | Theme accent color, no shadow (use only on dark backgrounds) |
| Max headline length | 6 words |
| Max subline length | 8 words |
| Case | Title Case (never ALL CAPS) |
| Emoji | Never |

## Placement Rules

- Position text block in **bottom 15%** of frame
- Left-align or center horizontally (be consistent within a platform set)
- Maintain minimum 40pt margin from bottom edge
- Ensure text is legible when thumbnail is shrunk to **200px wide** (test before export)
- Do not overlap critical UI elements (play buttons, focus rings, now-indicator line)

## Localization Notes

For localized submissions, keep headlines under 6 words in target language. German and French sublines may need +2 words; CJK languages typically need -2 words. Prioritize English screenshots for initial submission; add localized sets afterward.
